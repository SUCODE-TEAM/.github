### 📋 **The Sacred Contribution Ritual (S.H.I.E.L.D Protocol)**

**Step 1️⃣: SUIT UP - Fork the Repository**

```bash
# Clone your personal version
git clone https://github.com/YOUR_USERNAME/MCU-Repository.git
cd MCU-Repository

# Add upstream remote
git remote add upstream https://github.com/SUCODE-TEAM/MCU-Repository.git
```

**Step 2️⃣: CHOOSE YOUR WEAPON - Create Feature Branch**

```bash
# Update main branch
git fetch upstream
git checkout main
git merge upstream/main

# Create feature branch with sacred naming
git checkout -b feat/ironman-arc-reactor-v2
# OR
git checkout -b fix/thanos-snap-vulnerability
# OR
git checkout -b docs/asgardian-guide-update
```

**Branch Naming Convention (Mandatory):**
```
feat/       - New feature (feat/quantum-router)
fix/        - Bug fix (fix/memory-leak-redux)
docs/       - Documentation (docs/api-endpoints)
perf/       - Performance (perf/query-optimization)
refactor/   - Code refactor (refactor/component-structure)
test/       - Test coverage (test/auth-flow-coverage)
style/      - Code style (style/prettier-formatting)
chore/      - Maintenance (chore/dependency-update)
security/   - Security fix (security/xss-prevention)
```

**Step 3️⃣: FIGHT THE BUGS - Commit with Precision**

```bash
# Stage your changes
git add .

# Commit with semantic messaging (Must follow Conventional Commits)
git commit -m "feat(arc-reactor): implement quantum tunneling protocol

- Added Q-bit stabilization algorithm
- Improved energy efficiency by 300%
- Reduced latency from 50ms to 5ms
- Integrated Stark Industries monitoring

Closes #1337
Refs #1338, #1339"
```

**Step 4️⃣: CALL FOR BACKUP - Push & Create Pull Request**

```bash
# Push to your fork
git push origin feat/ironman-arc-reactor-v2

# Create Pull Request via GitHub CLI (Recommended)
gh pr create --title "feat: Implement Quantum Arc Reactor v2"
```
